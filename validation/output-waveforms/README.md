# Output Waveform Evidence

output_4p94v_5p6ohm_load.jpg is the scope capture showing approximately 4.94 V across the output load.

The corrected bench-load value for this capture is 5.6 ohm using Yageo SQP500JB-5R6, Digi-Key 5.6W-5-ND. The voltage is measured from the scope capture. The corresponding load current is approximately 882 mA calculated as 4.94 V / 5.6 ohm; it is not a direct current-probe measurement and is not a 1 A validation.

The stepped test sequence used the purchased 47 ohm, 10 ohm, and 5.6 ohm power resistors in descending order. At measured 4.94 V, the calculated currents were approximately 105 mA, 494 mA, and 882 mA respectively.

The numeric condition is recorded in output_4p94v_5p6ohm_load.csv.

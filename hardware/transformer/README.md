# Custom Flyback Transformer

Design, construction, measurement, BOM, and HiPot/insulation evidence for the production-grade prototype custom RM10/I flyback transformer.

| Folder | Description |

| hi-pot/ | HiPot video evidence for the approximately 2 kV-class test setup. |

## Pre-compliance evidence

The transformer package includes winding-insulation construction records and approximately 1.5 kVAC / 60 s HiPot testing. These results are documented as pre-compliance evidence against the applicable dielectric-strength and insulation requirements for the intended safety boundary. They are not certification, regulatory approval, or a production-release qualification.
